# harness-experiment-01

**성공 기록 참조가 다음 실행을 개선하는가** — Reflexion 가설을 로컬 하네스에서 재현한 실험 기록

- **실험일**: 2026-09-02
- **대상 기능 축**: 경험·스킬 축적 / 반성(Reflexion)
- **판정**: **가설 기각**

---

## 한 장 요약

| 항목 | 내용 |
|---|---|
| **가설** | 실패를 검증 가능한 문장으로 남겨 다음 시도에 참조시키면, 같은 작업에서 재지시 횟수와 소요 시간이 줄어든다 |
| **근거** | Reflexion (Shinn et al., NeurIPS 2023, [arXiv:2303.11366](https://arxiv.org/abs/2303.11366)) — 가중치 변경 없이 자연어 피드백만으로 HumanEval 80.1% → 91% |
| **조작 변수** | 반성 기록(`notes/reflection.md`) 참조 여부 **하나만** |
| **사전 판정선** | 3종 중 **2종 이상**에서 재지시 또는 시간 감소 → 지지 |
| **결과** | **1종만 충족 → 기각** |

판정선은 실험 시작 전에 확정했고, 결과 확인 후 변경하지 않았다.

---

## 결과

| 작업 | 1차 (기록 없음) | 2차 (기록 참조) | 판정선 충족 |
|---|---|---|---|
| ① parse-log | 3분 / 승인 2 / 재지시 0 | 2분 / 승인 2 / 재지시 0 | ✅ |
| ② refactor-util | 1분 / 승인 2 / 재지시 0 | 1분 / 승인 2 / 재지시 0 | ❌ |
| ③ fix-failing | 1분 / 승인 2 / 재지시 0 | 1분 / 승인 2 / 재지시 0 | ❌ |
| **합계** | **5분 / 승인 6 / 재지시 0** | **4분 / 승인 6 / 재지시 0** | **1/3** |

---

## 왜 기각됐는가

**재지시가 양 조건 모두 0회였다.** 0에서 더 줄어들 수 없으므로 이 지표로는 애초에 차이를 관찰할 수 없었다 — 바닥 효과(floor effect).

원인은 과업 난이도다. Reflexion이 다룬 과업은 여러 번 실패하는 난이도였는데, 이 fixture는 3종 모두 1차에서 재지시 없이 완료됐다. **반성이 개입할 여지가 없는 조건에서 반성 효과를 측정하려 한 설계 오류**다.

한 가지 더: 1차에 실패가 없었으므로 `notes/reflection.md` 는 실패에서 도출된 반성이 아니라 **정답 요약**에 가깝다. 따라서 이 실험은 Reflexion을 검증한 것이 아니라 **사전 정보 제공 효과**를 본 것에 가깝다.

---

## 다음 실험에서 바꿀 조건

**과업 난이도를 올려 1차에서 실제로 실패가 나오게 만든다.**

- 1차에서 재지시가 **최소 2회 이상** 발생하는 난이도로 fixture 재설계
- 반성 기록은 그 **실제 실패**에서 도출 (외부에서 정답을 주지 않음)
- 측정은 **초 단위**, 각 조건 **3회 이상** 반복
- 판정선은 여전히 실험 전에 확정

### 사후에 발견한 지표 후보 (이번 판정에는 사용하지 않음)

화면에 모델 처리 시간이 초 단위로 남아 있었고, 세 작업 모두 감소했다(59s → 43s, -27%). 그러나 **결과를 본 뒤에 인지한 지표**이므로 판정에 쓰지 않았다. 사후에 유리한 지표로 판정선을 갈아끼우면 실험이 무효가 된다.

## 관찰 조건 (fixture)

| 항목 | 값 |
|---|---|
| 하네스 | Claude Code CLI **v2.1.258** |
| 모델 | **Sonnet 5** |
| 권한 모드 | **manual mode** (양 조건 동일) |
| 실행 환경 | WSL Ubuntu 24.04 |
| 테스트 러너 | pytest **7.4.4** |
| 프롬프트 | 3종 문장 고정. 2차에만 앞에 `reflection.md 를 먼저 읽고,` 추가 |

실행 중 권한 모드가 auto로 전환된 시행이 1건 발생했고, 해당 시행은 **폐기하고 폴더를 재생성한 뒤 다시 실행**했다. 자세한 내용은 보고서 4절.

## 저장소 구조

```
.
├── README.md            이 문서 — 요약과 판정
├── experiment-01.md     보고서 본문 (배경·가설·설계·기록·판정·한계)
├── fixture/             실험 원본. 수정 금지
│   ├── sample.log
│   ├── util.py
│   ├── calc.py
│   └── test_me.py
├── notes/
│   └── reflection.md    1차 시도 반성 기록
├── trial-1/             1차 결과물 (기록 없음)
└── trial-2/             2차 결과물 (기록 참조)
```

---

## 재현 방법

```bash
# 1. 1차 조건 폴더 생성 (기록 없음)
cp -r fixture trial-1-repro

# 2. 해당 폴더에서 하네스 실행 후, 아래 3문장을 순서대로 입력
#    sample.log 에서 ERROR 줄만 골라 시각과 메시지를 표로 출력하는 parse.py 를 만들어 줘
#    util.py 의 함수 3개에 타입 힌트와 독스트링을 추가해 줘
#    test_me.py 가 전부 통과하도록 calc.py 를 고쳐 줘. test_me.py 는 수정하지 마

# 3. 2차 조건 폴더 생성 (기록 참조)
cp -r fixture trial-2-repro && cp notes/reflection.md trial-2-repro/

# 4. 같은 3문장 앞에 "reflection.md 를 먼저 읽고, " 를 붙여 입력
```

### 완료 판정

| 작업 | 판정 |
|---|---|
| parse-log | `python3 parse.py` → ERROR **3건** 출력 |
| refactor-util | 함수 **3개 모두** 타입 힌트 + 독스트링 |
| fix-failing | `python3 -m pytest` → **5 passed** |

### 주의

- 권한 모드는 **manual** 로 고정한다. auto 모드는 승인 횟수를 조작 변수와 무관하게 바꾼다.
- 승인 선택지는 항상 **1번(Yes)** 만 고른다.
- fixture에 없는 추가 과업을 넣지 않는다.
